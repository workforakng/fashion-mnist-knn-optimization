# Experimental Figures & Visual Diagnostics (`figures/`)

This directory contains the 15 diagnostic plots generated by `src/experiments.py` (stage IDs refer to `results/results.json`). The notebooks do **not** regenerate these files; they only display their own plots inline.

All accuracies below are fractions of the stated split: "fit" = 54,000 training images, "val" = 6,000 stratified validation images, "test" = the official 10,000 test images.

---

## Figure Catalog

| File Name | Stage | What the image actually shows |
| :--- | :---: | :--- |
| `01_class_distribution.png` | E0 | Class counts in the 60k development set: 6,000 images per class. |
| `02_samples.png` | E0 | A grid of sample images, one row per class. The row (class) names are not rendered (`set_ylabel` is called after `axis("off")`). |
| `03_pca_variance.png` | E2 | Cumulative explained variance vs. number of PCA components (1–128). The dashed red line marks **90 % variance**, reached at d ≈ 84 (ledger `var90_dim`). At d = 64 the curve is at **≈ 88 %** (88.1 % from the fitted PCA). |
| `04_pca_sweep.png` | E2 | **Validation** accuracy of a single KNN configuration (k = 5, Euclidean, uniform) vs. PCA dimension d ∈ {10, 20, 32, 48, 64, 80, 96, 128} plus the 90 %-variance point d = 84 (plotted last, which is why the line doubles back). Best d = 64 (val 87.33 %); the curve is flat (±0.2 pt) from 64 to 128. Only one metric is plotted. |
| `05_latency.png` | E5 | sklearn KNN query time for brute / kd_tree / ball_tree on raw-784 vs. PCA-64 features. Each bar is the time to classify all **6,000 validation queries** in one call (n_jobs = 4). Brute force: 2.98 s (raw) vs. 0.418 s (PCA-64), a **7.12×** speed-up. Tree backends are much slower in 784-D (80 s / 66 s). The y-axis label in this saved image ("1k val, median of 3") is wrong: 6,000 queries were used, and tree backends were timed once (brute: median of 3). |
| `06_bias_variance.png` | E4 | Train vs. validation accuracy of KNN (PCA-64, **uniform** weights) for k = 1, 3, …, 25. Validation peaks at k = 7 (87.37 %), but k = 5/7/9 are within 2 images of each other. Train accuracy at k = 1 is 1.0 by construction (each training query is its own nearest neighbour). |
| `07_optuna_history.png` | E3 | Validation accuracy of each of the 40 Optuna TPE trials (PCA fixed at 64; search over k, weights, metric). Dashed line = best trial, 87.82 % (k = 5, Manhattan, distance weights). Trials are joined by a line; no best-so-far curve is drawn. |
| `08_augmented.png` | E7 | The first 8 fit images (top) and one augmented draw of each (bottom) using hflip (p = 0.5), a ±2 px shift and random erasing. No crop is used. |
| `09_optimizer_compare.png` | E9 | Linear Soft-KNN (flip + shift + erase query augmentation) trained with Adam (blue, lr 1e-3), RMSprop (orange, lr 1e-3) and SGD with momentum 0.9 (green, lr 0.1). Left: train loss; right: validation accuracy. **SGD reaches the highest validation accuracy** (best 83.85 % vs. Adam 81.47 %, RMSprop 80.83 %) and early-stops after 7 epochs. The learning rates differ, so this is not a controlled comparison. |
| `10_tau_sweep.png` | E8 | Validation accuracy (left axis) and mean prediction entropy (right axis) of linear Soft-KNN models (flip + shift + erase query augmentation, up to 10 epochs) trained with τ ∈ {0.1, 0.2, 0.3, 0.5, 0.7, 1.0}. Accuracy falls steadily as τ grows; 0.1 is the best **tested** value and the edge of the grid (τ < 0.1 was not tested). Every model was scored at inference τ = 0.5, k = 7, which is why the entropy curve is nearly flat (0.927–0.937). |
| `11_softknn_curves.png` | E6 | Linear Soft-KNN (no augmentation), 8 epochs. Left: train loss only (no validation loss is plotted). Right: train vs. validation accuracy. Train accuracy (≈ 95–96 %) is **inflated** because each training query can match itself in the memory bank; see `src/README.md` ("Self-match"). The ≈ 8 pt train/val gap is mostly this artefact, not overfitting. |
| `12_confusion_matrix.png` | E25 | 10×10 confusion matrix on the 10,000 test images for the final E25 fusion (89.51 %). Per-class recall: Trouser 97.9 %, Bag 98.5 %, Sandal 96.6 %; worst class Shirt 61.7 %. Every fusion stage (E15, E17, E22, E24, E25, E27) writes this same file; it shows E25 because E25 was the last of them run. |
| `13_conv_curves.png` | E19 | Conv-metric Soft-KNN (seed 42, 30 epochs): train loss (left) and validation accuracy (right) per epoch. |
| `14_inference_grid.png` | E12 | Frozen linear Soft-KNN (`softknn_base.pt`). Left: validation accuracy vs. **inference** τ for k ∈ {3, 5, 7, 9, 11}; each line is flat, because τ rescales the logits and cannot change the arg-max. Right: mean normalised prediction entropy vs. inference τ (0.37 at τ = 0.1 → 0.98 at τ = 1.0). This is not a qualitative prediction grid. |
| `15_conv_shift_curves.png` | E20 | Training curves of the conv-metric Soft-KNN trained with ±2 px shift-augmented queries: train loss (left) and validation accuracy (right), which oscillates between 0.76 and 0.84 over 13 epochs. It is not a shift-robustness stress test. |
