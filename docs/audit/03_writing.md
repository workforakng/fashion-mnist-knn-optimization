## R. Suggested plain-language abstract (~150 words)

> k-nearest neighbors (KNN) is a simple classifier: it labels a new image with the most common label among the
> k most similar training images. On Fashion-MNIST, a dataset of 70,000 small clothing images, plain KNN reaches
> 85.24 % test accuracy. KNN has two weaknesses on images. Distances between 784-pixel images are all similar, and
> flattening an image loses which pixels are neighbors. We improve KNN in four steps. First, PCA reduces each
> image to 64 numbers, which raises accuracy to 86.43 % and makes search 7 times faster. Second, Soft-KNN replaces
> the hard vote with a smooth score, so a neural network can learn a better distance. Third, a small
> convolutional network learns this distance from the image's 2-D shape (87.63 %). Fourth, we combine several
> models, which gives 89.51 %. We also report what did not work. All code and a Colab notebook are public.
