\begin{abstract}
\noindent
The $k$-nearest neighbors (KNN) algorithm is one of the simplest and most intuitive machine learning models. To classify a new image, it searches through stored training examples and picks the majority class among its closest neighbors. While this simple rule works well on low-dimensional problems, it struggles on real-world image datasets like Fashion-MNIST (70{,}000 grayscale images of size $28\times28$ across 10 clothing categories). Plain KNN using Euclidean distance on raw pixels achieves only 85.24\,\% test accuracy and requires scanning all 54{,}000 training images for every single query. In this study, we systematically improve this pipeline while keeping its core principle: making final decisions using distances to stored training examples. First, reducing the input dimension with Principal Component Analysis (PCA) to 64 components preserves 88.1\,\% of the meaningful variance, boosts accuracy to 86.43\,\%, and speeds up query evaluation by $7.12\times$. Second, we introduce Soft-KNN, a differentiable framework that learns a better distance representation by mapping images into a unit hypersphere using a neural network and an instance memory bank. A linear projection reaches 87.10\,\%, while a small convolutional neural network that respects 2D spatial arrangement reaches 87.63\,\%. We then combine multiple random training seeds into an ensemble (88.06\,\%) and transfer this knowledge into a single compact student network (89.03\,\%). Finally, a convex fusion blending predictions across seven diverse metric heads with test-time augmentation achieves \textbf{89.51\,\%} test accuracy and \textbf{90.85\,\%} validation accuracy. Every experiment is recorded in our open-source results ledger (\file{results/results.json}) for verifiable reproduction.
\end{abstract}

\section{Introduction and Overall Approach}\label{sec:intro}
% =====================================================================
The $k$-nearest neighbors rule~\cite{cover1967} is non-parametric and intuitive: it stores the entire training dataset and labels an unseen query image by taking a majority vote among its $k$ closest neighbors. It requires no complex training step and produces transparent, instance-based predictions. However, when applied directly to raw images, classical KNN encounters two major practical obstacles:
\begin{enumerate}[leftmargin=1.4em]
\item \textbf{Curse of Dimensionality:} A $28\times28$ image lives in a 784-dimensional pixel space. In such high dimensions, pairwise distances between data points tend to concentrate, meaning that the distance to the nearest neighbor becomes very close to the distance to the farthest neighbor~\cite{beyer1999}. This makes finding meaningful neighbors difficult.
\item \textbf{Loss of Spatial Geometry:} Flattening a 2D image into a 1D vector of 784 pixel intensities ignores which pixels are adjacent, discarding vital spatial relationships like edges and silhouettes.
\item \textbf{Inference Bottleneck:} Classifying each query requires comparing it against all 54{,}000 stored training instances, leading to noticeable latency during real-time queries.
\end{enumerate}

\textbf{Dataset and Goal.} Fashion-MNIST~\cite{xiao2017} contains 70{,}000 $28\times28$ grayscale images across ten distinct clothing categories: T-shirt/top, Trouser, Pullover, Dress, Coat, Sandal, Shirt, Sneaker, Bag, and Ankle boot. There are 60{,}000 training images and 10{,}000 test images. Visually related classes (such as Shirt, T-shirt, and Coat) share similar silhouettes, making accurate separation challenging. Our objective is to determine how much we can improve classification performance and query efficiency on Fashion-MNIST while preserving the core mechanism of measuring distances against stored training exemplars.

\textbf{System Overview.} Figure~\ref{fig:pipeline} illustrates the stages of our complete solution. We begin by evaluating classical distance metrics on raw pixels and tuning KNN over PCA features. We then develop Soft-KNN, which makes neighbor assignment continuous and differentiable. Next, we replace flat projection vectors with a 2D convolutional network, train multiple models across diverse seeds, distill their collective predictions into a single student network, and combine our best models into an ensemble fusion.

\textbf{Related Work.} Metric learning aims to learn an embedding space where similar instances lie close together and dissimilar ones lie far apart. Neighborhood Components Analysis (NCA)~\cite{goldberger2004} introduced differentiable metric learning by replacing discrete majority votes with continuous softmax neighbor assignments. Large Margin Nearest Neighbor (LMNN)~\cite{weinberger2009} enforces a distance metric that keeps same-class neighbors within a local perimeter while pushing other classes outside a margin. Wu et al.~\cite{wu2018unsup,wu2018snca} demonstrated that storing features in an instance memory bank enables scalable, non-parametric neighborhood classification without re-encoding every image on every mini-batch. Knowledge distillation~\cite{hinton2015} compresses the rich posterior probabilities of an ensemble into a single compact model.

\section{Experimental Protocol and Baselines}\label{sec:protocol}
% =====================================================================
\textbf{Protocol.} To prevent any data leakage, we split the 60{,}000 training images into 54{,}000 \emph{fit} images and 6{,}000 \emph{validation} images using stratified sampling (seed 42), which maintains identical class proportions across both splits. The official 10{,}000 test images are never used for model selection, parameter tuning, or early stopping; they are evaluated strictly once to report the final unbiased generalization performance. All pixel values are normalized to $[0, 1]$.

\textbf{Measurement Uncertainty.} On a test set of $N=10{,}000$ examples, the binomial standard error (SE) for an accuracy $p \approx 89\,\%$ is $\sqrt{p(1-p)/N} \approx \pm0.3$\,percentage points (pp). This indicates that accuracy differences smaller than roughly 0.6\,pp between single experimental runs cannot be reliably distinguished from statistical noise.

\subsection{Classical Distance Metrics on Raw Pixels}\label{sec:metrics}
For a query image $x$ and a stored example $x'$, we evaluate three standard distance formulas:
\begin{equation}
\delta_2(x,x') = \lVert x-x'\rVert_2, \quad
\delta_1(x,x') = \textstyle\sum_{j=1}^{D}|x_j-x'_j|, \quad
\delta_{\cos}(x,x') = 1-\frac{x^\top x'}{\lVert x\rVert_2\,\lVert x'\rVert_2}.
\end{equation}
The classical KNN classifier identifies the set $\mathcal{N}_k(x)$ containing the $k$ nearest training examples and predicts the class by majority vote: $\hat{y}(x)=\argmax_{c\in\{0,\dots,9\}}\sum_{i\in\mathcal{N}_k(x)} w_i \mathbb{1}[y_i=c]$.

Principal Component Analysis (PCA) finds the directions along which the training images show the greatest variation. We compute PCA eigenvectors exclusively on the 54{,}000 fit samples. Figure~\ref{fig:pca}(b) shows validation accuracy of Euclidean KNN across varying dimensions $d$. Performance peaks at $d=64$ (87.33\,\%) and levels off thereafter. On the test set, PCA-64 Euclidean KNN reaches 85.63\,\% (+0.39\,pp over raw pixels).

\subsection{Bias--Variance Trade-off, Optuna Tuning, and Query Latency}\label{sec:biasvar}
Figure~\ref{fig:biasvar} displays the bias--variance trade-off as we vary $k\in\{1,3,\dots,25\}$ on PCA-64 features (E4). When $k$ is very small, the classifier fits individual training points too closely, making it vulnerable to noise (high variance). When $k$ is large, the neighborhood expands too far into other classes, causing over-smoothing (high bias). Validation accuracy peaks at $k=7$ (87.37\,\%), with values between $k=5$ and $k=9$ exhibiting virtually identical performance.

\textbf{Optuna Optimization.} We ran a 40-trial Bayesian search using Optuna~\cite{akiba2019} to jointly tune $k$, the distance metric, and neighbor voting weights on PCA-64 features (E3). The winning configuration chose $k=5$, Manhattan distance, and inverse-distance weighting ($w_i = 1/\delta_i$), which gives closer neighbors greater influence. This model achieved 87.82\,\% validation accuracy and \textbf{86.43\,\%} test accuracy (+1.19\,pp over baseline E1).

\section{Soft-KNN: Learning Better Distances}\label{sec:softknn}
% =====================================================================
\subsection{Mathematical Formulation}\label{sec:softknn-model}
Classical majority voting is a step function: changing input weights slightly does not change the vote counts, so the gradient is zero almost everywhere. To allow gradient-based training, Soft-KNN replaces the discrete vote with a smooth, continuous probability distribution.

Let $f_\theta: \mathbb{R}^{784} \to \mathbb{R}^{128}$ be a neural network parameterized by weights $\theta$. We project each embedding onto the unit hypersphere: $z = f_\theta(x)/\lVert f_\theta(x)\rVert_2 \in \mathbb{S}^{127}$. A memory bank holds the normalized embeddings $b_1, \dots, b_N$ ($N=54{,}000$) of all training images along with their labels $y_1, \dots, y_N$. For a query $z$ and each class $c\in\{0,\dots,9\}$, let $\mathcal{A}_c(x)$ denote the $m$ closest bank examples belonging to class $c$. The mean distance to class $c$ is:
\begin{equation}
\bar\delta_c(x) = \frac{1}{m} \sum_{i \in \mathcal{A}_c(x)} \lVert z - b_i \rVert_2.
\end{equation}
We convert these class distances into continuous probabilities using a temperature parameter $\tau > 0$:
\begin{equation}
P_\tau(y = c \mid x) = \frac{\exp\left(-\bar\delta_c(x)/\tau\right)}{\sum_{c'=1}^{C} \exp\left(-\bar\delta_{c'}(x)/\tau\right)}.
\label{eq:softknn}
\end{equation}
The network is trained by minimizing the cross-entropy loss $\mathcal{L} = -\log P_\tau(y \mid x)$ over mini-batches.

\textbf{Decision Rule and Role of Temperature.} At test time, the predicted class is simply $\hat{y}(x) = \argmin_c \bar\delta_c(x)$, which picks the class whose nearest examples are closest on average. This follows the local-mean classification rule~\cite{mitani2006}. The temperature $\tau$ scales the sharpness of the probability output and shapes training gradients, but it does not change the top-ranked predicted class during testing. Gradients flow directly through $\lVert z-b_i\rVert_2$ into the query embedding $z$. The memory bank entries $b_i$ are kept detached and are refreshed periodically (once per epoch for linear models; every 107 steps for CNNs)~\cite{wu2018unsup,wu2018snca}.

\subsection{Linear Projections, Temperature Sensitivity, and Optimizers}\label{sec:linear}
The linear Soft-KNN model (E6) maps 784 pixels to 128 dimensions using a projection matrix $W \in \mathbb{R}^{128\times784}$ initialized with PCA eigenvectors. Trained with Adam (learning rate $10^{-3}$, batch size 256, $m=7$, $\tau=0.5$), E6 reaches 88.22\,\% validation accuracy and \textbf{87.10\,\%} test accuracy (+0.67\,pp higher than tuned PCA-KNN E3). Adding 2-pixel shifted copies of images into the memory bank (E14) yields 87.13\,\% test accuracy. Conversely, a 3-layer MLP (784--256--128, E16) performed worse, reaching only 85.70\,\%.

\textbf{Temperature Sensitivity.} When sweeping training temperature $\tau \in [0.1, 1.0]$ on the linear backbone (E8, Figure~\ref{fig:tau}), validation accuracy drops steadily as $\tau$ increases. Because normalized embeddings have distance bounded in $[0, 2]$, setting $\tau=1.0$ caps the maximum predicted probability at roughly 45\,\%, preventing strong gradient updates. Setting $\tau=0.1$ yielded the highest validation accuracy (86.53\,\%).

\textbf{Optimizer Study.} In our optimizer pilot experiment E9 (Figure~\ref{fig:optim}), SGD with momentum 0.9 (learning rate 0.1) attained 86.22\,\% re-scored validation accuracy, outperforming Adam (82.50\,\%, lr $10^{-3}$) and RMSprop (82.72\,\%, lr $10^{-3}$). While SGD proved effective for simple linear weights, our deeper convolutional networks utilized Adam with gradient clipping at 1.0 for reliable optimization stability.

\section{Convolutional Metric Backbone, Distillation, and Fusion}\label{sec:conv}
% =====================================================================
\subsection{Convolutional Backbone and Multi-Seed Ensembling}\label{sec:convmodel}
Because a flat matrix multiplication ignores image layout, we replace $W$ with a small Convolutional Neural Network (CNN). The network contains two convolutional stages ($3\times3$ filters with 32 and 64 channels, ReLU non-linearities, and $2\times2$ max-pooling), followed by a linear layer projecting to 128 dimensions. Trained with Adam (learning rate $3\times10^{-4}$, batch size 256, 30 epochs), a single model E19 ($m=9, \tau=0.1$) achieves 89.07\,\% validation accuracy and \textbf{87.63\,\%} test accuracy (+0.53\,pp over the linear Soft-KNN model).

\textbf{Multi-Seed Ensemble.} To test consistency, we trained three identical CNN models using three separate random seeds $\mathcal{S}=\{42, 7, 123\}$ with automatic mixed precision (AMP). Their individual test accuracies were 87.53\,\%, 86.92\,\%, and 87.57\,\% (mean: $87.34\pm0.36\,\%$; spread: 0.65\,pp). Combining their predictions by averaging output probabilities $\bar{P}(c\mid x) = \frac{1}{3}\sum_{s\in\mathcal{S}} P^{(s)}(c\mid x)$ (E21) achieves \textbf{88.06\,\%} test accuracy (+0.72\,pp over the average seed), demonstrating the benefit of ensembling.

\subsection{Knowledge Distillation}\label{sec:distill}
Running three separate networks at inference time increases compute requirements. To retain ensemble benefits within a single network, we distill the ensemble into a student CNN~\cite{hinton2015}. For each training image $x_i$, our 3-seed teacher ensemble produces soft probability targets $p^{\mathrm{T}}(x_i)$ evaluated at $m=9, \tau=1.0$. The student network minimizes a weighted sum of standard cross-entropy and Kullback--Leibler (KL) divergence:
\begin{equation}
\mathcal{L} = (1-\lambda)\,\mathrm{CE}\big(y, \operatorname{softmax}(h)\big) + \lambda\,T^{2}\,\mathrm{KL}\big(p^{\mathrm{T}} \,\Vert\, \operatorname{softmax}(h/T)\big),
\end{equation}
where $h_c(x)=-\bar\delta_c(x)/\tau$ ($T=1.0, \lambda=0.5$). Trained on Kaggle GPUs, this distilled student (E23) achieves 90.10\,\% validation accuracy and \textbf{89.03\,\%} test accuracy (+0.97\,pp above the teacher ensemble and +1.40\,pp above individual teachers), showing that soft probability targets provide effective regularization.

\subsection{Test-Time Augmentation and Convex Ensemble Fusion}\label{sec:fusion}
Test-Time Augmentation (TTA) evaluates each test image across six variations (original, horizontal flip, and four 1-pixel directional shifts) and averages the predictions. Our final prediction is a convex combination over $J$ candidate metric models:
$P(y=c\mid x) = \sum_{j=1}^{J} w_j P_j(y=c\mid x)$, where $w_j \ge 0$ and $\sum_j w_j = 1$.
We search through all weight combinations on a grid with step size 0.1 (8{,}008 total weight vectors) to maximize validation accuracy.

\subsection{Error Analysis and Confusion Matrix}\label{sec:errors}
Figure~\ref{fig:cm} shows the normalized test confusion matrix for model E25. Garments with distinctive silhouettes achieve high classification recall: Bag (98.5\,\%), Trouser (97.9\,\%), Sneaker (97.0\,\%), and Ankle boot (95.4\,\%). Misclassifications occur almost exclusively between upper-body garments: Shirt reaches only 61.7\,\% recall, with 16.0\,\% of shirts confused with T-shirts, 10.4\,\% with Pullovers, and 7.1\,\% with Coats. In low-resolution ($28\times28$) grayscale images, fine textures such as collars, buttons, and stitching are difficult to resolve, creating natural visual overlap among these categories.

\textbf{Why Certain Changes Degraded Performance.} On-the-fly training augmentation (E7, E13, E20) reduced accuracy by up to $-5.42$\,pp. While standard neural networks benefit from input distortions, instance-based memory bank models struggle when an artificially altered query tries to retrieve clean, unaltered exemplars stored in the memory bank. A second generation of distillation (E26) dropped accuracy by $-2.03$\,pp because compounding approximation errors from multiple teacher models overwhelmed the capacity of the student network.

\section{Limitations, Reproducibility, and Conclusion}\label{sec:conclusion}
% =====================================================================
\textbf{Limitations.} (1) \emph{Self-Matching During Training:} Because training examples are also present in the memory bank, training queries match themselves at distance zero during loss calculation. While this did not affect test evaluation, we have added an opt-in \texttt{--exclude-self} flag in \file{src/softknn.py} for future research. (2) \emph{Validation Set Reuse:} Reusing the 6{,}000 validation images to evaluate several model choices explains why the validation score (90.85\,\%) is higher than the unbiased test score (89.51\,\%). (3) \emph{Statistical Resolution:} With binomial standard error around $\pm0.3$\,pp, small differences under 0.6\,pp remain within normal noise variation.

\textbf{Reproducibility.} The open repository contains complete reproduction scripts and ledgers:
\begin{itemize}[leftmargin=1.4em]
\item \texttt{python -m src.experiments --scale full --stages E1,E2,...}: runs the experimental pipeline and logs results into \file{results/results.json}.
\item \texttt{python scripts/train\_conv\_seed.py} and \texttt{python scripts/train\_distill.py}: trains the multi-seed convolutional backbones and the student network.
\item \texttt{python scripts/rerun\_classical.py}: reproduces the classical KNN sweeps and latency benchmarks in \file{results/classical_reruns.json}.
\item \texttt{bash docs/build\_papers.sh}: automatically compiles all four per-member student PDF reports.
\end{itemize}

\textbf{Conclusion.} This work shows that instance-based nearest neighbor classification can be substantially improved through learned metric projections while maintaining the clarity of distance-based decisions. Moving from raw-pixel KNN (85.24\,\%) through PCA optimization (86.43\,\%), differentiable Soft-KNN (87.63\,\%), distillation (89.03\,\%), and multi-source convex fusion achieves \textbf{89.51\,\%} test accuracy on Fashion-MNIST.
